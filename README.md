# 🗽 NYC Airbnb Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project focuses on a comprehensive Exploratory Data Analysis of the New York City Airbnb dataset. I am currently analyzing the pricing trends, host behaviors, and location-based insights to uncover the underlying patterns of the short-term rental market in NYC.

> ⚠️ **Note:** This project is currently a work in progress. Further statistical modeling and feature engineering updates are made regularly.
